# Certificate Tracker: Automated Portfolio & Activity Point Manager

Certificate Tracker is a cross-platform application designed to digitize, organize, and manage professional and academic credentials. By combining secure cloud storage with automated activity point allocation, the platform provides a unified dashboard for users to track their extracurricular progress and safeguard their achievements.

---

## Overview
Managing physical certificates and tracking cumulative institutional activity points is a tedious, fragmented process. This project provides a centralized digital vault that not only stores documents securely but also parses and aggregates achievement data to track academic and professional milestones in real-time.

## Problem Statement
Students and professionals often lose track of vital credentials scattered across emails, local drives, and physical folders. Furthermore, academic institutions require the manual auditing of "activity points" for graduation, creating administrative bottlenecks and making it difficult for users to track their real-time progress.

## Solution
Certificate Tracker offers a mobile-first, cloud-backed solution where users can upload their credentials to a secure vault. The system categorizes these documents, automatically tallies the associated activity points, and visualizes the user's progress through an intuitive, reactive dashboard.

---

## Features
* **Secure Document Vault:** Cloud-native storage for PDFs and images with strict read/write security rules.
* **Automated Activity Point Allocation:** Dynamic calculation of institutional activity points based on uploaded and verified credentials.
* **Reactive User Dashboard:** Real-time UI updates reflecting new uploads, point accumulations, and categorical breakdowns.
* **Role-Based Authentication:** Secure login system differentiating between standard users and verification administrators.
* **Cross-Platform Compatibility:** Built using html, css and javascript can run on any device.
